# 孤胆枪手：蜂巢浩劫

一款类《孤胆枪手》(Alien Shooter) 的 **PC 端斜俯视角射击闯关游戏**，纯 HTML5 / Canvas / 原生 JavaScript 实现，**零外部依赖、零素材**（贴图、图形与音效全部代码生成），双击即玩。

## 快速开始

**方式一：直接打开**（最简单）
双击 `index.html` 即可游玩（建议 Chrome / Edge 最新版）。

**方式二：本地服务器**
```bash
node serve.js        # 默认端口 8123
node serve.js 9000   # 指定端口
```
浏览器访问 `http://127.0.0.1:8123`

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| `鼠标左键`（按住） | 射击 |
| `鼠标右键` | 投掷手雷（有冷却） |
| `空格` | 冲刺（短暂无敌，有冷却） |
| `1 ~ 7` / 滚轮 | 切换武器（全部武器开局可用） |
| `Esc` | 暂停 / 继续 |

## 游戏内容

- **主界面**：单人模式 / 多人模式（未开放，点击提示）/ 图鉴 / 设置 / **开发者模式**，底部显示历史最佳战绩
- **魂斗罗风入场动画**：每次进入主界面（含开局与战斗中返回）播放——白屏闪光 → 红色 SOLDIER 展开 → 巨型标题缩放砸入 + 模糊消散 → 副标题上滑展开 → "按任意键开始"闪烁；任意键/点击可跳过，随后菜单按钮依次弹入
- **炫酷主界面**：渐变描金标题呼吸发光、主按钮脉冲光晕、斜向光带扫过、菜单背景升级（远景环状星球 + 流星 + 星云 + 余烬粒子）
- **开场剧情**：5 页背景故事（打字机动画，可点击加速 / 跳过），之后进入战斗
- **斜俯视角与贴图**：程序化**沙土贴图**地面（室外荒漠营地与室内统一为沙土色）；第一关为**大型实验室**（沙色瓷砖地面、实验台/培养槽/仪器/储物柜贴图，出口=实验室大门）；后续关卡为荒漠营地；墙体/障碍立体、按纵深排序遮挡，影子投影在角色侧下方
- **场景细节**：沙地有沙丘明暗带、骸骨、弹坑、金属废料、血迹拖痕、外星尖刺植物、沙袋掩体、倒伏电线杆；实验室有中央实验区标记、出口警示条、地面电缆、培养槽碎玻璃、散落文件、通风口格栅、墙根菌毯、地面裂缝等，全部程序化随机铺陈
- **角色**：2.5D 士兵（头盔/护甲/四肢关节），**待机完全静止**、移动时双腿摆步、双臂持枪，**初始武器为双枪**（左右手各一把、双手抓握，交替开火）
- **关卡制闯关**（借鉴《孤胆枪手》区域推进）：共 **8 关**
  1. 实验室入口 → 2. 实验走廊 → 3. 深层实验室 → 4. 冷藏库
  5. 孵化室（**首领：孵化护卫**）→ 6. 服务器核心 → 7. 巢穴通道 → 8. 蜂巢核心（**最终首领：蜂巢之母**）
- **怪物海量涌入**：怪物不再固定一批，而是**持续从四面八方刷新**（带红色出生特效），每关需击杀目标数（第 1 关 30 只 → 第 7 关 120 只），击杀越快刷新越密；Boss 关击杀过半后首领现身混战
- **推进方式**：击杀数达标并清空场上敌人 → 出口大门开启（门上方漂浮箭头 + 屏幕边缘**绿色箭头**持续指向出口门位置）→ 走到门前往下一区域；每关地图重新生成、障碍随关卡变多；过关回血 45% + 弹药补给
- **补给箱系统**：每关地图上有 **1 个武器箱**（黄色 ? 光柱）、**2 个弹药箱**（绿光，箱盖印当前武器外形）与 **1 个急救箱**（红十字）；**打怪不掉血包/弹药**（仅小概率掉手雷），弹药与生命全靠箱子与过关补给；弹药/生命已满时无法拾取（不消耗、不刷屏）
- **拾取物建模**：血包 = **红十字急救箱**；弹药 = **印有对应武器外形的弹药箱**（盖子图案随当前手持武器变化）
- **武器成长**：初始只有**双枪**（无限弹药，保底武器）；霰弹枪、冲锋枪、突击步枪、等离子炮、火焰喷射器、加特林均需从武器箱获取；**武器弹药用尽会自动切回双枪**
- **首领战**：Boss 有**红色攻击前摇预警**（扩散红圈 = 弹幕、脚下红圈 = 锁定射击、红点 = 召唤、虚线箭头 = 冲锋），且**屏幕边缘有骷髅箭头指示 Boss 方位**
- **敌人**：全部改为**双足机械异形**（两段液压腿 + 发光膝关节、装甲板与铆钉、发光护目眼、分节机械尾、金属前爪、刀锋尾尖），形态各异——工蚁小、迅捷瘦长、重装粗壮、首领巨型；**远程单位（酸液喷射者）背部驮一门酸液发射器**（蓄能脉冲发光）、**自爆者肚皮绑炸弹背心**（红灯闪烁 + 导火索火花）、精英/重装/Boss 有更高等级装甲
- **开发者模式**（主菜单或暂停菜单进入，设置自动保存）：**无敌** / **无限弹药** / **解锁全部武器** / **移速翻倍** / **立即通关当前关卡**（暂停菜单里跳关后自动回到游戏，直接看到出口箭头），开启时 HUD 显示「⚒ 开发者模式」角标
- **7 种武器**（1-7 切换，外形各不相同；除双枪外均需武器箱获取，**开火时枪身会后坐踢起**、枪口喷火）：
  双枪（初始 · 无限弹药）、霰弹枪、冲锋枪、突击步枪、等离子炮、火焰喷射器、加特林（后坐震动已调轻）
- **8 种异形**：工蚁、迅捷、酸液喷射者、自爆者、精英猎杀者、重装异形、孵化护卫、蜂巢之母
- **图鉴**：敌人（击杀解锁）/ 武器 / **关卡** / 档案，进度自动保存
- **设置**：音量、音效/音乐、难度（简单/普通/困难）、屏幕震动、伤害数字
- **通关反馈**：胜利有金色粒子演出 + **S/A/B/C 作战评级**（按剩余生命）+ 完整统计（关卡、击杀、得分、用时、历史最佳）
- **通关黑屏演出**：击败最终首领后黑屏切入动画——星空漂移 + **地球升起旋转**（大气光晕、大陆滚动、云带、出现脉冲环）→ 金色打字机 "**你 已 拯 救 地 球**" → 副标题"蜂巢核心已被摧毁 · 人类重获新生" → 淡出揭示结算面板；点击可跳过
- **程序化 BGM**（Web Audio 零资源合成）：主菜单为**舒缓电影风主题**（92 BPM，温暖失谐垫 + 正弦低音 + 柔和拨弦琶音 + 轻鼓，Am–F–C–G）；**进入游戏后不播放音乐**（只有音效），返回主菜单恢复播放。另保留一套激烈的战斗变奏代码（未启用，可随时切回）

## 项目结构

```
alien-shooter-roguelike/
├── index.html           # 页面与界面骨架
├── serve.js             # 本地预览服务器
├── css/style.css        # 界面样式
├── js/
│   ├── config.js        # ★ 数值配置（武器/敌人/8 关关卡表/难度/剧情文案）
│   ├── utils.js         # 数学工具
│   ├── audio.js         # 合成音效 + 背景音乐
│   ├── input.js         # 键鼠输入
│   ├── codex-data.js    # 图鉴数据
│   ├── entities.js      # 玩家/敌人/子弹/拾取物/粒子 + Boss 前摇
│   ├── map.js           # 场地/立体障碍物/血迹/出生点
│   ├── levels.js        # 关卡系统（敌人构成、出口门、补给）
│   ├── scenes.js        # 主菜单/剧情/图鉴/设置界面逻辑
│   ├── game.js          # 主循环/斜视角渲染/火柴人/HUD/Boss 指示器
│   └── main.js          # 启动入口
└── test/
    ├── smoke.js         # 冒烟测试（node test/smoke.js）
    └── fullrun.js       # 全自动机器人通关模拟（node test/fullrun.js [难度]）
```

## 如何修改

- **武器 / 敌人数值**：`js/config.js` 的 `CFG.WEAPONS` 与 `CFG.ENEMIES`
- **关卡构成**：`js/config.js` 的 `CFG.LEVELS`（每关敌人表 / 是否首领）
- **Boss 技能与前摇**：`js/entities.js` 的 `bossAI` / `beginCast` / `executeCast` / `drawTelegraph`
- **出口门 / 补给**：`js/levels.js`
- **角色 / 武器外形**：`js/game.js` 的 `_drawPlayer` / `drawWeaponShape`
- **敌人机械形态**：`js/entities.js` 的 `DINO` 表与 `drawDino`
- **贴图与实验室布局**：`js/map.js` 的 `makeSandTile` / `makeLabTile` / `_buildLab` / `_paintOutdoorDecor` / `_paintLabDecor`
- **开发者模式**：`js/scenes.js`（面板与存取） + `js/game.js`（grantAllWeapons / devSkipLevel）+ `js/entities.js`（无敌/无限弹/移速钩子）
- **剧情文案**：`js/config.js` 的 `STORY_SLIDES`
- **图鉴文案**：`js/codex-data.js`
- **界面样式**：`css/style.css`

## 已知设计说明

- 进度（图鉴击杀记录、设置、最佳战绩）保存在浏览器 `localStorage`，清除浏览器数据会重置。
- 贴图、图形与音效均为代码实时生成，无版权素材风险，可放心分发。
- 角色与怪物为程序化绘制，后续可替换为正式立绘 / 模型。
- 后续可扩展：更多关卡与 Boss 模式、武器自定义、地图变体、真正的多人联机等。
